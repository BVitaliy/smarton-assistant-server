# База знань SMARTon для AI-консультанта

Файли з цієї теки (крім тих, що починаються з `_`) склеюються в алфавітному
порядку й цілком потрапляють у системний промпт консультанта.

Правила:
- Пишіть факти, а не рекламу. Модель відповідає лише тим, що тут є.
- Ціни сюди НЕ пишемо: вони приходять з API або з App Store / Google Play.
- Рядки, що починаються з `TODO`, — нотатки для команди: при завантаженні
  вони вирізаються, модель їх не бачить. Поки TODO не заповнено, консультант
  на ці питання відповідатиме «не знаю» і пропонуватиме підтримку.
- Будь-яка зміна тексту автоматично скидає кеш готових відповідей.
- Мова — українська. Модель сама перекладає відповідь мовою юзера.
