# База знань помічника PRONTO

Що тут — сталі факти, які не змінюються щодня. Акції, графік, контакти, зони
доставки, меню й ціни помічник бере **з API апки в момент питання** (tools),
тож їх сюди не писати — вони застаріють.

- Файли з `_` на початку в промпт не потрапляють (як цей).
- Рядки, що починаються з `TODO`, теж відкидаються — це нагадування для
  контент-менеджера.
- Після змін — передеплоїти сервер.
